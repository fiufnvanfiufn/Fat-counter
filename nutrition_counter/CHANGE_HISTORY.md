# История изменений

## 2026-10-10 — Дневник питания: Завтрак, Обед, Ужин, Перекусы и база продуктов

### Реализация

* **Интерактивный дневник приёмов пищи:** В раздел «Дневник и статистика» добавлены 4 категории приёмов пищи (🌅 Завтрак, ☀️ Обед, 🌙 Ужин, 🍏 Перекусы) с кнопкой «+ Добавить блюдо».
* **База продуктов (Dataset):** Добавлен встроенный каталог популярных здоровых блюд и продуктов (`FOOD_DATASET`) с калорийностью и БЖУ, а также быстрому поиску по названию.
* **Добавление собственных блюд:** Добавлена форма ввода произвольного блюда с ручным указанием калорий, белков, жиров, углеводов и веса порции.
* **Динамический перерасчёт нутриентов:** Добавление и удаление блюд из дневника мгновенно пересчитывает потреблённые калории, оставшийся лимит и процент выполнения норм БЖУ.
* **Сохранение в localStorage:** Все добавленные и удалённые приёмы пищи сохраняются в браузере пользователя (`fat_counter_meals_v1`).

## 2026-10-10 — Расширение интерфейса: Навигация, Статистика, Избранное и Профиль

### Реализация

* **Переключение разделов:** Реализован полноценный бесшовный роутинг в `app.js` между 4 разделами: «Чат с помощником», «Статистика рациона», «Избранные материалы» и «Профиль и цели».
* **Раздел «Статистика»:** Добавлен наглядный обзор калорий за день, прогресс-бары БЖУ (белки, жиры, углеводы), динамический недельный график калорийности и рекомендации от ассистента.
* **Раздел «Избранное»:** Реализована возможность добавления карточек источников в избранное прямо из диалога чата или всплывающего окна. Добавлена фильтрация по категориям (статьи, советы, рецепты) и удаление материалов.
* **Раздел «Профиль и цели»:** Добавлена форма личных параметров (возраст, вес, рост, дневная норма калорий, цель по белкам, пищевые ограничения). Изменения автоматически синхронизируются со статистикой и сохраняются в `localStorage`.
* **Улучшения UX/UI и адаптивности:**
  * Исправлен позиционный оверлей мобильного меню (`body.menu-open::after`) для узких экранов.
  * Добавлена поддержка безопасных зон снизу на мобильных устройствах (`env(safe-area-inset-bottom)`).
  * Оптимизированы размер шрифта `textarea` на мобильных (16px) для предотвращения нежелательного масштабирования на iOS.
  * Реализовано добавление вопросов в чат и переход из любых разделов.

### Документация

* Обновлён `README.md` с описанием нового функционала и возможностями разделов.

### Выполненные проверки реализации

* `node --check nutrition_counter/frontend/app.js` и `node --check nutrition_counter/frontend/server.mjs` — успешно (exit code 0).
* `git diff --check` — успешно, ошибок форматирования нет (exit code 0).

## 2026-10-09 — первая версия макета и актуализация SDD

### Реализация

* Добавлен адаптивный русскоязычный интерфейс чата с подсказками, ожиданием ответа, карточками источников и новым разговором.
* Использованы HTML5, CSS3, Vanilla JavaScript и встроенные SVG. Локальный сервер реализован на Node.js 18+ без внешних зависимостей и сборки.
* Добавлены заготовленные ответы и вымышленные статьи с маркировкой демонстрационного режима. BM25 и LLM не подключены.
* В README добавлены команды запуска и описание ограничений.

### Документация

* В техническом SDD зафиксированы использованный стек, структура, состояния интерфейса, локальный сервер и границы будущей RAG-интеграции.
* Продуктовый SDD согласован с первой версией: отделены демонстрационные ответы от будущих результатов LLM/BM25, дополнены критерии приёмки.
* Добавлены инструкции AGENTS.md: чтение спецификаций, порядок изменений по SDD, ограничения стека и проверка результата.

### Выполненные проверки реализации

* `node --check` для `frontend/app.js` и `frontend/server.mjs` — успешно.
* Локальный запуск и HTTP GET для `/` и `/app.js` — статус 200.
* `git diff --check` — успешно при проверке реализации.
