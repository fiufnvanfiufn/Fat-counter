# История изменений

## 2026-10-09 — первая версия макета и актуализация SDD

### Реализация

* Добавлен адаптивный русскоязычный интерфейс чата с подсказками, ожиданием ответа, карточками источников и новым разговором.
* Использованы HTML5, CSS3, Vanilla JavaScript и встроенные SVG. Локальный сервер реализован на Node.js 18+ без внешних зависимостей и сборки.
* Добавлены заготовленные ответы и вымышленные статьи с маркировкой демонстрационного режима. BM25 и LLM не подключены.
* В README добавлены команды запуска и описание ограничений.

### Документация

* В техническом SDD зафиксированы использованный стек, структура, состояния интерфейса, локальный сервер и границы будущей RAG-интеграции.
* Продуктовый SDD согласован с первой версией: отделены демонстрационные ответы от будущих результатов LLM/BM25, дополнены критерии приёмки.
* Добавлены инструкции AGENTS.md: чтение спецификаций, порядок изменений по SDD, ограничения стека и проверка результата.

### Выполненные проверки реализации

* `node --check` для `frontend/app.js` и `frontend/server.mjs` — успешно.
* Локальный запуск и HTTP GET для `/` и `/app.js` — статус 200.
* Разовая проверка логики через Node.js VM с имитацией DOM: блокировка ввода, предотвращение повторной отправки, два источника, открытие описания, безопасный вывод текста и сброс во время ожидания — успешно. Это не браузерный тест и не сохранённый тестовый набор.
* `git diff --check` — успешно при проверке реализации.
* Полная визуальная и браузерная проверка не выполнена: встроенный браузер завершался с ошибкой среды. Адаптивность и клавиатурные сценарии требуют проверки в рабочем браузере.
