### Проект "Помощник по дневному контролю калорий" (Fat-counter)

## Команда
* **Продукт и интерфейс:** До Тхе Фу
* **Интеграция:** Чичев Иван
* **BM25 и RAG:** Щеблецов Лев

## Текущее состояние
Текущее состояние: Полноценный адаптивный веб-интерфейс с ИИ-чатом, дневником питания по приёмам пищи (Завтрак, Обед, Ужин, Перекусы), статистикой нутриентов, избранным и профилем. **Backend на FastAPI** с хранением данных в SQLite (профиль, дневник, избранное, база продуктов, mock-чат).

## Локальный запуск

### Backend (FastAPI + SQLite)

Требуется **Python 3.10+**.

```bash
cd nutrition_counter/backend
python3 -m venv .venv
source .venv/bin/activate        # Linux/macOS
# .venv\Scripts\activate         # Windows
pip install -r requirements.txt
uvicorn main:app --host 127.0.0.1 --port 8000 --reload
```

Откройте **http://localhost:8000**. Backend раздаёт и API, и статические файлы фронтенда.

API-документация (Swagger UI): **http://localhost:8000/docs**

### Frontend-only (без backend, устарело)

Если нужен только фронтенд с localStorage (старый режим):

```powershell
node nutrition_counter/frontend/server.mjs
```

Откройте **http://localhost:3000**.

## API endpoints

| Метод | Путь | Описание |
|-------|------|----------|
| GET | `/api/profile` | Получить профиль пользователя |
| PUT | `/api/profile` | Обновить профиль |
| GET | `/api/meals` | Список приёмов пищи |
| POST | `/api/meals` | Добавить блюдо |
| DELETE | `/api/meals/{id}` | Удалить блюдо |
| DELETE | `/api/meals` | Очистить весь дневник |
| GET | `/api/sources` | Список источников |
| GET | `/api/sources/{id}` | Получить источник |
| PATCH | `/api/sources/{id}/bookmark` | Переключить избранное |
| GET | `/api/foods?q=...` | Поиск по базе продуктов |
| POST | `/api/chat` | Отправить вопрос (mock-ответы) |

## Возможности приложения

* **Чат с ассистентом:** Диалог с визуальным набором текста, поддержкой `Enter` / `Shift+Enter`, подсказками популярных вопросов и безопасным выводом текста.
* **Дневник питания и категория приёмов пищи:** Учёт блюд по 4 приёмам пищи: 🌅 Завтрак, ☀️ Обед, 🌙 Ужин, 🍏 Перекусы.
* **База продуктов (Dataset):** Поиск и выбор готовых блюд из предустановленной базы знаний или добавление собственного блюда с калориями и БЖУ.
* **Статистика и автоматический перерасчёт:** Автоматический перерасчёт потреблённых калорий за день, оставшегося лимита, процентных прогресс-баров БЖУ и недельного графика.
* **Избранные материалы:** Добавление источников из чата в избранное, фильтрация по категориям (статьи, советы, рецепты) и удаление.
* **Профиль и цели:** Персональные настройки пользователя (возраст, вес, рост, дневной калораж, белки и пищевые ограничения) с сохранением на сервере.
* **Адаптивная навигация:** Выдвижное боковое меню для мобильных устройств, обработка клавиши `Escape` и мобильных безопасных зон (`env(safe-area-inset-bottom)`).
