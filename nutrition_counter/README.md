### Проект "Помощник по дневному контролю калорий" (Fat-counter)

## Текущее состояние
Текущее состояние: Полноценный адаптивный веб-интерфейс с ИИ-чатом, дневником питания по приёмам пищи (Завтрак, Обед, Ужин, Перекусы), статистикой нутриентов, избранным и профилем.

## Локальный запуск

Требуется **Node.js 18 или новее**. Устанавливать зависимости не нужно.

Из корня репозитория `Fat-counter` выполните:

```powershell
node nutrition_counter/frontend/server.mjs
```

Откройте **http://localhost:3000**. Остановка сервера — `Ctrl+C`.

Если порт 3000 занят, можно выбрать другой:

```powershell
$env:PORT = 3001
node nutrition_counter/frontend/server.mjs
```

После этого откройте **http://localhost:3001**.

## Возможности приложения

* **Чат с ассистентом:** Диалог с визуальным набором текста, поддержкой `Enter` / `Shift+Enter`, подсказками популярных вопросов и безопасным выводом текста.
* **Дневник питания и категория приёмов пищи:** Учёт блюд по 4 приёмам пищи: 🌅 Завтрак, ☀️ Обед, 🌙 Ужин, 🍏 Перекусы.
* **База продуктов (Dataset):** Поиск и выбор готовых блюд из предустановленной базы знаний или добавление собственного блюда с калориями и БЖУ.
* **Статистика и автоматический перерасчёт:** Автоматический перерасчёт потреблённых калорий за день, оставшегося лимита, процентных прогресс-баров БЖУ и недельного графика.
* **Избранные материалы:** Добавление источников из чата в избранное, фильтрация по категориям (статьи, советы, рецепты) и удаление.
* **Профиль и цели:** Персональные настройки пользователя (возраст, вес, рост, дневной калораж, белки и пищевые ограничения) с сохранением в `localStorage`.
* **Адаптивная навигация:** Выдвижное боковое меню для мобильных устройств, обработка клавиши `Escape` и мобильных безопасных зон (`env(safe-area-inset-bottom)`).
