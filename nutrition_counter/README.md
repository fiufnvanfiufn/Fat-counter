## Локальный запуск макета

Требуется **Node.js 18 или новее**. Устанавливать зависимости не нужно.

Из корня репозитория `Fat-counter` выполните:

```powershell
node nutrition_counter/frontend/server.mjs
```

Откройте **http://localhost:3000**. Остановка сервера — `Ctrl+C`.

Если терминал уже открыт в каталоге `nutrition_counter`, используйте:

```powershell
node frontend/server.mjs
```

Если порт 3000 занят, в PowerShell можно выбрать другой:

```powershell
$env:PORT = 3001
node frontend/server.mjs
```

После этого откройте http://localhost:3001.

## Что можно посмотреть

* Адаптивный интерфейс чата: главный экран, подсказки вопросов и мобильное меню.
* Отправку своего вопроса кнопкой или клавишей `Enter`; `Shift+Enter` добавляет новую строку.
* Индикатор генерации и блокировку ввода на время подготовки ответа.
* Ответ и две карточки статей с открываемыми описаниями.
* Начало нового разговора, в том числе во время загрузки.

Реализована первая версия из `spec/product/product.md`: **только фронтенд-макет**.
Ответы, названия статей и их описания — демонстрационные заготовки, обозначенные
в интерфейсе и в `frontend/app.js`. BM25 и LLM не подключены, введённые вопросы
не отправляются на внешние сервисы. Для вопросов о замене свинины, белке, обеде
и перекусах предусмотрены отдельные примеры; остальные вопросы получают общий
демонстрационный ответ. История хранится только на странице и сбрасывается
при её перезагрузке. Сервер слушает только локальный адрес `127.0.0.1`.
