# Технический SDD: архитектура

## Статус и назначение

Реализован интерактивный веб-интерфейс с ИИ-чатом, дневником приёмов пищи (Завтрак, Обед, Ужин, Перекусы), каталогом продуктов, статистикой калорий/БЖУ, разделом Избранное и профилем пользователя. Данные хранятся на сервере в SQLite и доступны через REST API.

## Использованный стек

| Слой | Технологии | Назначение |
| --- | --- | --- |
| Разметка | HTML5, семантические элементы, нативный `dialog` | Чат, дневник приёмов пищи, модальные окна, форма профиля |
| Оформление | CSS3, Flexbox, Grid, media queries, CSS animations | Адаптивный макет, прогресс-бары БЖУ, карточки приёмов пищи |
| Логика | Vanilla JavaScript, DOM API, Fetch API | Роутинг, подсчёт калорий, дневник питания, поиск по базе продуктов, взаимодействие с REST API |
| Иконки | Встроенные SVG symbols | Локальные иконки без внешних сервисов |
| Backend | Python 3.10+, FastAPI 0.115, Pydantic 2.10 | REST API сервер, валидация данных, раздача статических файлов фронтенда |
| База данных | SQLite 3, aiosqlite 0.20 | Асинхронное хранение профиля, дневника, источников и базы продуктов |
| Сервер (устар.) | Node.js 18+, ES modules | Локальный HTTP-сервер статических файлов (`server.mjs`), заменён backend |

## Архитектура

```
┌──────────────┐       HTTP (fetch)       ┌──────────────────┐
│   Браузер    │ ◄──────────────────────► │  FastAPI (8000)   │
│  index.html  │   /api/profile           │   main.py         │
│  app.js      │   /api/meals             │   schemas.py      │
│  styles.css  │   /api/sources           │   database.py     │
└──────────────┘   /api/foods             └────────┬─────────┘
                   /api/chat                       │
                                                   ▼
                                           ┌──────────────┐
                                           │   SQLite DB   │
                                           │ fat_counter.db│
                                           └──────────────┘
```

FastAPI раздаёт статические файлы фронтенда (`/`) и предоставляет REST API (`/api/*`).

## API endpoints

| Метод | Путь | Описание |
| --- | --- | --- |
| GET | `/api/profile` | Получить профиль пользователя |
| PUT | `/api/profile` | Обновить профиль |
| GET | `/api/meals` | Список приёмов пищи |
| POST | `/api/meals` | Добавить блюдо |
| DELETE | `/api/meals/{id}` | Удалить блюдо |
| DELETE | `/api/meals` | Очистить весь дневник |
| GET | `/api/sources` | Список источников |
| GET | `/api/sources/{id}` | Получить источник |
| PATCH | `/api/sources/{id}/bookmark` | Переключить избранное |
| GET | `/api/foods?q=...` | Поиск по базе продуктов |
| POST | `/api/chat` | Отправить вопрос (mock-ответы) |

## Сохранение данных

Данные дневника питания, профиля, избранных статей и базы продуктов хранятся в серверной базе данных SQLite (`fat_counter.db`). При первом запуске база автоматически создаётся и заполняется начальными данными (seed). Файл `localStorage` браузера больше не используется.

## Файловая структура backend

```
backend/
├── main.py            # FastAPI-приложение, эндпоинты, mock-ответы чата
├── database.py        # Слой работы с SQLite (создание таблиц, seed, подключение)
├── schemas.py         # Pydantic-модели запросов и ответов
├── requirements.txt   # Зависимости Python
├── .gitignore         # Игнорирование .venv/, __pycache__/, fat_counter.db
└── .venv/             # Виртуальное окружение (не в git)
```
