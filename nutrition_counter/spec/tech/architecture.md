# Технический SDD: архитектура

## Статус и назначение

Реализован интерактивный веб-интерфейс с ИИ-чатом, дневником приёмов пищи (Завтрак, Обед, Ужин, Перекусы), каталогом продуктов (`FOOD_DATASET`), статистикой калорий/БЖУ, разделом Избранное и профилем пользователя.

## Использованный стек

| Слой | Технологии | Назначение |
| --- | --- | --- |
| Разметка | HTML5, семантические элементы, нативный `dialog` | Чат, дневник приёмов пищи, модальные окна, форма профиля |
| Оформление | CSS3, Flexbox, Grid, media queries, CSS animations | Адаптивный макет, прогресс-бары БЖУ, карточки приёмов пищи |
| Логика | Vanilla JavaScript, DOM API, `localStorage` | Роутинг, подсчёт калорий, дневник питания, поиск по базе продуктов |
| Иконки | Встроенные SVG symbols | Локальные иконки без внешних сервисов |
| Сервер | Node.js 18+, ES modules | Локальный HTTP-сервер статических файлов (`server.mjs`) |

## Сохранение данных

Данные дневника питания (`fat_counter_meals_v1`), профиля (`fat_counter_profile_v1`) и избранных статей (`fat_counter_sources_v1`) сохраняются в `localStorage` браузера пользователя.
